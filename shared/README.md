# Shared Resources

This directory contains reusable logic, contracts, constants, and utilities shared across the BC Smart Lifestyle ecosystem.

## Purpose

Shared resources prevent duplication and ensure consistency across modules.

These resources may be used by:

* Platform (Flutter)
* Backend APIs
* Drone systems
* Security services
* Analytics

---

## Directory Structure

| Folder     | Purpose                        |
| ---------- | ------------------------------ |
| contracts/ | Shared communication contracts |
| constants/ | Shared system constants        |
| utilities/ | Shared reusable helper logic   |

---

## Benefits

* Reduced duplication
* Standardized communication
* Easier maintenance
* Stronger consistency
