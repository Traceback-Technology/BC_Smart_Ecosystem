# BC Ways

BC Ways is the smart campus navigation module.

## Purpose

Provides:

* Campus navigation
* Shortest-path generation
* GPS tracking
* Route recalculation

---

## Directory Structure

| Folder              | Purpose                      |
| ------------------- | ---------------------------- |
| pathfinding-engine/ | Route calculation algorithms |
| navigation-service/ | Navigation orchestration     |
| gps-tracking/       | Real-time location tracking  |

---

## Features

BC Ways supports:

* Indoor/outdoor campus navigation
* Real-time route updates
* Dynamic rerouting
* GPS-assisted wayfinding
