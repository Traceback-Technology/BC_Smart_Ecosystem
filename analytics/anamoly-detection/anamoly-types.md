# Anomaly Types

## Authentication Anomalies

Examples:

- Multiple failed logins
- Rapid login attempts
- Suspicious session activity

---

## Order Anomalies

Examples:

- Abnormally high order volume
- Duplicate orders
- Payment inconsistencies

---

## Navigation Anomalies

Examples:

- Excessive rerouting
- GPS inconsistencies
- Invalid path requests

---

## Drone Anomalies

Examples:

- Low battery
- GPS signal loss
- Delivery failure
- Unexpected route deviation
