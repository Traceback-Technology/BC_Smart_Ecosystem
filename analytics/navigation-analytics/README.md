# Navigation Analytics

This module analyzes navigation behaviour within BC Ways.

## Purpose

Tracks:

* Popular campus routes
* Building traffic
* Navigation efficiency
* Route recalculation frequency

---

## Metrics

### Most Visited Locations

Examples:

* Reception
* Cafeteria
* Lecture halls

### Route Popularity

Most frequently used paths.

### Average Travel Time

Measures route efficiency.

### Route Recalculation

Tracks how often users go off-route.

---

## Benefits

Navigation analytics helps:

* Improve campus wayfinding
* Detect congestion areas
* Improve shortest-path recommendations
