# Logging Policy

## Authentication Logs

Track:

- Login attempts
- Failed authentication
- Token expiry
- Permission denials

---

## API Logs

Track:

- Endpoint usage
- Error rates
- Request timing

---

## Drone Logs

Track:

- Battery level
- GPS coordinates
- Failed dispatch
- Return-home events

---
