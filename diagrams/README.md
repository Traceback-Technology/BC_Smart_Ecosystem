
# System Diagrams

This directory contains system diagrams for BC Smart Lifestyle.

## Purpose

The diagrams help visualize:

* System architecture
* Communication flow
* Database structure
* Navigation algorithms
* Drone delivery workflow
* Authentication process

These diagrams are used for:

* Developer onboarding
* Architecture discussions
* Project documentation
* Academic submission support

---

## Directory Structure

| Folder        | Purpose                    |
| ------------- | -------------------------- |
| architecture/ | High-level system diagrams |
| erd/          | Database and graph models  |
| flowcharts/   | Process workflows          |

---
