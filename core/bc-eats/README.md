# BC Eats

BC Eats is the smart tuckshop ordering module.

## Purpose

Provides:

* Digital food ordering
* Menu browsing
* Payment processing
* Delivery management

---

## Directory Structure

| Folder               | Purpose                   |
| -------------------- | ------------------------- |
| menu-management/     | Tuckshop menu handling    |
| order-management/    | Order lifecycle           |
| payment-processing/  | Payment handling          |
| delivery-management/ | Drone and pickup delivery |

---

## Features

Supports:

* Online ordering
* Real-time order tracking
* Drone delivery
* Collection orders
