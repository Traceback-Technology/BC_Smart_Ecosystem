# Security

This directory contains security-related architecture and documentation for BC Smart Lifestyle.

## Purpose

The security layer protects:

- User authentication
- Role-based access
- Visitor access
- API security
- Drone access permissions
- Monitoring and threat detection

---

## Directory Structure

| Folder | Purpose |
|--------|---------|
| access-control/ | Authorization and permissions |
| QR-auth-system/ | Visitor QR access |
| monitoring/ | Logging and security monitoring |

---

## Security Principles

The system follows:

- Least Privilege Access
- Role-Based Authorization
- JWT Authentication
- Secure API Communication
- Audit Logging
