# Order Analytics

This module provides analytics for BC Eats ordering behaviour.

## Purpose

Tracks:

* Popular menu items
* Peak ordering hours
* Average order values
* Delivery demand
* Drone delivery requests

---

## Metrics

Examples:

### Daily Orders

Total orders placed per day.

### Popular Menu Items

Most frequently ordered meals.

### Peak Ordering Times

High-demand periods.

Example:

```txt
12:00 - 14:00
```

### Delivery Method Usage

Compare:

* Collection
* Drone delivery

---

## Benefits

Order analytics helps:

* Reduce food shortages
* Improve inventory planning
* Optimize preparation times
