# Validation Utilities

## Student Number Validation

Rules:

* Must be numeric
* Must be valid Belgium Campus format

---

## Password Validation

Rules:

* Minimum 8 characters
* At least one number
* At least one uppercase letter

---

## GPS Validation

Rules:

Latitude:

```txt id="2g4d90"
-90 to 90
```

Longitude:

```txt id="9m7zlh"
-180 to 180
```

---

## Order Validation

Checks:

* Menu item exists
* Quantity greater than 0
* Payment successful
